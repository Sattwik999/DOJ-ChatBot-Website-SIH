# ⚖️ NYAAY - DOJ ChatBot Website for Smart India Hackathon

**A modern legal information platform with AI-powered chatbot assistance for the Department of Justice, built for Smart India Hackathon (SIH).**

Hi! I'm Sattwik Sarkar, and this is my project for the Smart India Hackathon: NYAAY - a comprehensive legal information website with an integrated AI chatbot built with React, TypeScript, and Botpress. I created this platform to make legal information more accessible to citizens and provide instant assistance through intelligent conversation.

---

## 🎯 Why I Built This

I wanted to bridge the gap between complex legal information and everyday citizens who need quick, reliable answers to their legal questions. This project helped me learn about building accessible government services, integrating AI chatbots, and creating user-friendly interfaces for legal information systems. The platform aims to democratize legal knowledge and make justice more accessible to all.

Whether you're a citizen seeking legal guidance, a developer interested in legal tech, or a government official looking for digital solutions, NYAAY provides a modern approach to legal information dissemination.

## 🛠️ Setup & Installation

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** or **yarn**

### 1. Clone the Repository
```bash
git clone https://github.com/Sattwik999/DOJ-ChatBot-Website-SIH.git
cd DOJ-ChatBot-Website-SIH
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
The application will be available at `http://localhost:5173`

### 4. Build for Production
```bash
npm run build
```

### 5. Preview Production Build
```bash
npm run preview
```

## 🎮 Usage Guide

### For Citizens
1. **Browse Legal Information** - Explore different law divisions and their explanations
2. **Access Official Resources** - Click on navigation links to visit official government websites
3. **Chat with AI Assistant** - Use the floating chat button (💬) to get instant legal guidance
4. **Mobile Access** - Access the platform from any device, anywhere

### For Developers
1. **Customize Components** - Modify React components in `src/components/`
2. **Update Styling** - Edit Tailwind classes or add custom CSS
3. **Integrate APIs** - Add new legal data sources or government services
4. **Extend Chatbot** - Customize Botpress configuration for specific legal domains
